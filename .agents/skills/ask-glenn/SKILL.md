# Ask Glenn

Use `/ask-glenn` when you are unsure which skill applies. Invoke a skill by its
name, or read its linked `SKILL.md` for the full workflow; this navigator only
points you to the right instructions.

- [`/ask-glenn`](SKILL.md): choose a skill from this list.
- [`/agent-orchestration`](../agent-orchestration/SKILL.md): plan and build
  non-trivial features or tasks through design, implementation, and review.
- [`/code-review`](../code-review/SKILL.md): review current changes, a branch,
  or a pull request.
- [`/codebase-design`](../codebase-design/SKILL.md): design deep modules with
  small interfaces and clean seams.
- [`/domain-modeling`](../domain-modeling/SKILL.md): sharpen domain terms and
  record decisions in the glossary and ADRs.
- [`/fallow`](../fallow-skills/fallow/skills/fallow/SKILL.md): run Fallow
  analysis for cleanup, duplication, architecture, risk, and related checks.
- [`/fallow-review`](../fallow-skills/fallow/skills/fallow-review/SKILL.md):
  review changes using Fallow's graph-grounded structural findings.
- [`/grilling`](../grilling/SKILL.md): challenge a design or plan through
  focused questions.
- [`/grill-with-docs`](../grill-with-docs/SKILL.md): grill through a design
  while building the domain model and recording decisions.
- [`/handoff`](../handoff/SKILL.md): prepare a concise handoff for another
  agent or session.
- [`/implement`](../implement/SKILL.md): implement one spec or a set of
  tickets using TDD and code review.
- [`/implement-spec`](../implement-spec/SKILL.md): implement a spec by working
  its ticket graph with agents.
- [`/improve-codebase-architecture`](../improve-codebase-architecture/SKILL.md):
  find and explore opportunities to deepen modules.
- [`/setup-matt-pocock-skills`](../setup-matt-pocock-skills/SKILL.md):
  configure the issue tracker, triage labels, and domain docs for these skills.
- [`/merge-safety`](../merge-safety/SKILL.md): decide whether a PR is safe for an
  agent to merge.
- [`/template-authoring`](../template-authoring/SKILL.md): add, redesign, or
  fix a LivePage Template.
- [`/template-design-review`](../template-design-review/SKILL.md): evaluate
  and improve a Template's preview-mode design in the browser.
- [`/tdd`](../tdd/SKILL.md): build a feature or fix through red-green-refactor.
- [`/to-tickets`](../to-tickets/SKILL.md): turn a plan, spec, or conversation
  into dependency-linked, agent-ready tickets.
- [`/triage`](../triage/SKILL.md): triage issues into clear states and prepare
  agent-ready briefs.
- [`/typesafe-ai`](../typesafe-ai/SKILL.md): build AI features using TypeSafe
  judgments and probabilities.
- [`/zip-branch-import`](../zip-branch-import/SKILL.md): import a patch and
  related assets from a zip archive.
